### tools\system\hardware_inspector.py
> PROJECT JAMES — Hardware Inspector (P3-1)

PC 하드웨어 성능을 자동 측정해서 "무기/장비" 형식으로 반환.

설계 철학:
  자메스 = 두뇌(지적 능력)
  하드웨어 = 무기/장비 (두뇌를 실행하는 물리 인프라)

  CPU  → ⚔️ 검  (연산 속도 = 공격력)
  RAM  → 🛡️ 방패 (메모리 = 방어력/지구력)
  GPU  → 🪄 마법봉 (병렬 추론 = 마법 능력)
  Disk → 🎒 가방 (저장 용량 = 지식 수납)
  NET  → 🌐 망토 (네트워크 = 이동 능력)
- 크기: 430줄 / 15KB
- 주요 함수: _get_cpu, _get_ram, _get_gpu, _get_disk, _cpu_level, _ram_level, _gpu_level, _disk_level
- 의존성: typing, os, platform, sys

### tools\web\web_searcher.py
> PROJECT JAMES — Web Searcher (3-E)

웹 검색 + 지식 연동 모듈.

검색 엔진 우선순위:
  1순위: Tavily  (AI 특화, 무료 1,000회/월, TAVILY_API_KEY 환경변수 필요)
  2순위: DuckDuckGo (무료, API 키 불필요, 자동 fallback)
  → Tavily 할당량 소진 또는 오류 시 DuckDuckGo로 자동 전환

단기/장기 지식 분리 원칙:
  [경로 A] 챗 대화 → 단기 시작
    retrieval score 낮음 → 자동 웹 검색
    → conv
- 크기: 507줄 / 18KB
- 주요 함수: _search_tavily, _search_duckduckgo, search_web, get_search_engine_status, format_search_results, fetch_url_content, enrich_results_with_content, classify_domain
- 의존성: os, time, typing, pathlib, datetime, re
